Privacy Policy — Zunda Diet Poster

Last updated: November 9, 2026

1. Overview

Zunda Diet Poster (the "Tool") is a personal tool used only by the owner of the TikTok account @diet.elementaryschool to publish the owner's own videos to that same account via TikTok's official APIs. The Tool has no other users.

2. Information the Tool handles

The Tool handles only the following, all belonging to the owner:

  • TikTok OAuth access tokens and refresh tokens issued when the owner authorizes the Tool (scopes: video.upload, video.publish, and basic profile information needed to identify the authorized account).
  • Video files, titles, and captions that the owner prepares for publication.

The Tool does not collect information about any other person, does not track viewers, and does not use analytics or advertising services.

3. How the information is used

Tokens are used only to authenticate the owner's requests to the TikTok Content Posting API. Video files and captions are used only to publish them to the owner's TikTok account.

4. Storage and sharing

Tokens and video files are stored on the owner's own computer systems. Information handled by the Tool is never sold, rented, or shared with third parties, except for transmission to TikTok's official API endpoints as required for publishing.

5. Retention and deletion

The owner may revoke the Tool's access at any time from TikTok's authorization settings, which invalidates the stored tokens. Stored tokens and files can be deleted by the owner at any time.

6. Changes

This policy may be updated from time to time. The current version is always available on this page.

7. Contact

Questions about this policy can be sent via the TikTok account @diet.elementaryschool.
